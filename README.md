# TimeGetter

> A lightweight and intuitive web tool for tracking hours, clocking in/out, and workday management.

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Status](https://img.shields.io/badge/status-in%20development-blue)](#)

TimeGetter is a sleek web application designed to easily track and manage your daily working hours.

## Features

- **Clock In & Out:** Manual entry or instant one-click timestamping via the "NOW" button.
- **Lunch Break Management:** Toggleable break tracking with precise start and end time inputs.
- **Daily Target:** Custom working hour quota setup for each day.
- **Real-Time Tracking:** Central display showing total time worked alongside a visual progress bar.
- **Balance & Overtime Carryover:** Integrates previous balance (Day-1 counter) with dynamic updates to your overall balance.
- **End-of-Day Notifications:** Automatic alert as soon as the daily goal is reached.
- **History & Themes:** Session history log and toggle between dark and light modes.
- **Wrap-up Button:** Dedicated action to save data and complete the workday in a single click.
